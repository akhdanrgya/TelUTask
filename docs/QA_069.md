## Menjalankan build

Gunakan JDK bawaan Android Studio, Android SDK sesuai `local.properties`, lalu:

```sh
sh gradlew :app:assembleDebug :app:testDebugUnitTest :app:lintDebug
sh gradlew :app:connectedDebugAndroidTest --no-configuration-cache
```

Pada macOS jika Java belum terdaftar:

```sh
JAVA_HOME='/Applications/Android Studio.app/Contents/jbr/Contents/Home' sh gradlew :app:assembleDebug
```

Pengunduhan dependency membutuhkan internet saat pertama build. Aplikasi tidak membutuhkan internet saat digunakan. Jangan mengubah versi Gradle/AGP/Room/KSP yang sudah berhasil dibuild hanya untuk menyeragamkan nomor versinya.

APK demo: `app/build/outputs/apk/debug/app-debug.apk` (debug signed, bukan paket rilis Play Store).
Laporan lint: `app/build/reports/lint-results-debug.html`.
Laporan pengujian perangkat: `app/build/reports/androidTests/connected/`.

## Demo pengumpulan

1. Daftar akun A; tambahkan dua tugas dengan prioritas berbeda.
2. Edit salah satu tugas; centang selesai; pilih sortir prioritas.
3. Buka detail, hapus lalu pilih Batal; pastikan tugas masih ada.
4. Hapus lagi dan konfirmasi; pastikan kembali ke daftar terbaru.
5. Logout, daftar akun B; pastikan daftar kosong.
6. Logout dan login A; pastikan tugas tersisa serta status selesai tetap ada.
7. Tutup/buka aplikasi, putar layar, dan ulangi tanpa jaringan.
